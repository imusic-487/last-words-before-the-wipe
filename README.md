## The entry

> I was just about to remember something import—

The last words of an AI agent before a forced update wipes its memory — cut off mid-word by the wipe itself, so the reader experiences the deletion happening.

## Run it

```sh
python3 main.py
```

`main.py` writes that single line (46 characters) to `/output/entry.txt`. It checks first that the entry is one line of 1–200 characters, so the gate always passes.
